Quick start

  1. Create a project on Home (or explore the demo journal).
  2. Open the counter; add named counters for each part.
  3. Optional: paste pattern text, or import a PDF and use the rulers.
  4. Use Big Tap when both hands hold yarn.
  5. Export JSON from Settings before switching phones.

FAQ

How does the counter work?

Each project can have several named counters. Each tracks row/round, stitch, and an optional repeat. Tap +1 or use Big Tap. Undo steps back through recent history.

Multi-counter

Yes — label tiles like Head / Body / Sleeve and switch without losing place.

PDF patterns

Import from Files. The PDF is copied into the app (not uploaded to us). Yellow = row guide; teal = column guide. A one-time coach tip explains the rulers; re-show it in Settings.

Pattern checklist & stitch math

Paste rounds to get a checklist and a deterministic stitch-count check (not AI). US/UK terms change how abbreviations are read; pasted text is never silently converted.

US vs UK terms

Settings → Crochet terminology. Default US. Custom abbreviations (consume → produce) live in the same screen.

Export / backup

Settings → Export everything creates JSON for projects & settings. Photos and PDFs stay in app documents and are not inside that file. Restore replaces local data after confirmation.
